# 推しルナ占い 🌙🐈

月と星と白猫がテーマの、スマートフォン向け推し活診断サイトです。
4つの質問に答えると、回答の組み合わせに応じた占い結果を表示します。

コンセプト：推しを好きな気持ちも、自分のことも大切に。

## 特徴

- 外部API・外部フォント・有料サービスを使わない静的サイト（HTML / CSS / JavaScript のみ）
- ビルド不要。`index.html` をブラウザで開くだけで動作します
- 全256通りの回答の組み合わせに対応

## 結果の内容

| 項目 | 決まり方 |
| --- | --- |
| 推し活スタイル（16種） | 4つのルナタイプ（月光・星座・流れ星・白猫）の1位×2位 |
| 今日の推し活運（★1〜5） | 回答＋今日の日付（同じ日は同じ結果、日付が変わると変化） |
| 意外な気づき（16種） | Q3の回答×1位タイプ |
| ラッキーアクション | Q4（いま欲しいもの）別のリストから日替わりで2つ。カラー・アイテム・時間帯も表示 |
| 白猫からのお守りメッセージ | 推し活スタイル（16種）ごとに「今のあなたへ／月からのメッセージ／心のお守り／明日へのひとこと」の4つ |

## ファイル構成

```
index.html        画面（トップ / 質問 / 占い中 / 結果）
css/style.css     デザイン
js/data.js        質問と結果の文章データ（文章の追加・修正はここ）
                  お守りメッセージは STYLES の各結果の omamori に、見出しは OMAMORI_SECTIONS にあります
images/           公式マスコット（三日月と白猫）とホーム画面用アイコン
js/fortune.js     結果を組み立てるロジック
js/app.js         画面遷移・シェア・前回結果の保存
tests/check.js    全組み合わせの検証スクリプト（お守りメッセージの欠け・使い回し・禁止表現もチェック）
```

## 確認方法

```sh
# ロジックの検証（Node.js）
node tests/check.js

# ブラウザで確認（同じWi-Fiのスマホからも http://<PCのIP>:8000 で見られます）
python3 -m http.server 8000
```

### iPhoneでのプレビュー

1. PCとiPhoneを同じWi-Fiにつなぐ
2. このフォルダで `python3 -m http.server 8000` を実行する
3. PCのIPアドレスを調べる（Mac：「システム設定 → Wi-Fi → 詳細」、Windows：`ipconfig` の IPv4 アドレス）
4. iPhoneのSafariで `http://<PCのIPアドレス>:8000` を開く

この方法は https ではないため、「結果をシェアする」は共有メニューではなく、結果をコピーする動作になります。
共有メニューは https で公開したあと（GitHub Pages など）に表示されます。

## 公開

GitHub Pages などの静的ホスティングに、このフォルダをそのまま置けば公開できます。
