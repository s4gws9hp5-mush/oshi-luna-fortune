# 推しルナ占い 🌙🐈

「推しを好きな気持ちも、自分のことも大切に。」

推し活をしている人が、毎日の占いを楽しみながら、自分らしい推し活スタイルを知れるスマートフォン向けサイトです。

- 外部API・外部フォント・サーバー・有料サービスを使わない静的サイト（HTML / CSS / JavaScript のみ）
- ビルド不要。GitHub Pages にこのフォルダをそのまま置けば公開できます
- 結果はこの端末のブラウザ（localStorage）にだけ保存されます。ブラウザのデータを消すと保存した結果も消えます

## 2つの体験

### 今日の推し活占い（毎日）

トップの「今日の推し活占いを見る！」を押すと、約1秒の読み込み演出のあとに表示されます。

- 日付は日本時間で判定し、毎日0時に切り替わります（端末のタイムゾーンが日本以外でも同じ）
- 同じ日は何度見ても同じ結果です。その日に最初に出た結果を保存し、日付が変わるまで同じものを表示します
- 表示内容：今日の運勢（★1〜5）・今日のあなたへのメッセージ・ラッキーアクション2つ・ラッキーカラー（色見本つき）/アイテム/時間帯・白猫からのお守りメッセージ
- 推し活タイプを診断済みなら、メッセージ・ラッキーアクション・お守りの言葉がタイプに合わせた内容になります。運勢の★・ラッキー・お守りは全員共通です（タイプで有利・不利が出ないように）
- 「前回の結果を見る」で、直近の占いを日付つきで見返せます（最大7日分を保存）

### 推し活タイプ診断（固定タイプ）

10問に答えると、8つのタイプのどれかに決まります。日付や乱数は使わないので、同じ回答なら必ず同じタイプです。

| タイプ | |
| --- | --- |
| 🌙 月夜のおひとりさま鑑賞家 | 📣 ときめき全力応援隊長 |
| 📷 思い出アルバムコレクター | 💬 推し語りコミュニケーター |
| 🌱 そっと寄りそう見守りさん | 🎨 ときめき探究クリエイター |
| ☁️ マイペースな癒やし系ファン | 🔭 情報キャッチの星読みリサーチャー |

- 判定：選んだ選択肢の main のタイプに2点、sub のタイプに1点。合計点が最も高いタイプになります
- 同点のとき：main に選ばれた回数 → main に選ばれた質問の早さ → 点が入った質問の早さ → `TYPE_ORDER` の順
- 各タイプは main・sub ともにちょうど5回ずつ登場するので、どのタイプも出やすさはほぼ同じ（11〜13%）です
- 回答は1問ごとに保存され、途中で閉じても「続きから」再開できます
- 診断済みの人がもう一度診断して別のタイプになったときは、「保存する」を押すまで前のタイプのままです
- 旧4問版の診断の保存データ（`oshi-luna-last`）は消さずに残していますが、新しいタイプとしては使いません

### 推し活タイプのシェア画像

タイプ結果の「📸 結果をシェアする」で、タイプ名・キャッチコピー・タイプ専用の白猫・#推しルナ占い・サイトのアドレスが入った画像（1080×1350）を、ブラウザの中で作ります（`js/share-card.js`）。

- 画像を共有できるブラウザ（https で開いた iPhone の Safari など）では「画像をシェアする」で共有メニューに画像を添付
- 共有できないときは「画像を保存する」か、画像の長押しで保存
- 「タイプ名とURLをコピー」で文章だけコピーもできます

### 翌日の占いを試すとき（日付のお試し表示）

URL の最後に `?preview-date=2026-10-19` のように日付を付けると、その日の「今日の推し活占い」を表示できます（保存中のタイプも反映）。
お試し表示の結果は保存されません。例：`https://s4gws9hp5-mush.github.io/oshi-luna-fortune/?preview-date=2026-10-19`

## 文章や質問を直すとき

すべて `js/data.js` にあります。

| 直したいもの | 場所 |
| --- | --- |
| タイプの説明（9項目） | `TYPES` の各タイプ |
| タイプ別の今日のメッセージ・アクション | `TYPES` の各タイプの `daily` |
| 質問と配点 | `QUESTIONS`（`main` に2点・`sub` に1点） |
| 今日の運勢・お守り・未診断の人へのメッセージ | `LUCK`・`DAILY` |
| ラッキーカラー・アイテム・時間帯 | `LUCKY_COLORS` などと、色コード `LUCKY_COLOR_CODES`・アイコン `LUCKY_ITEM_ICONS` / `LUCKY_TIME_ICONS` |

文章を直したら `node tests/check.js` を実行してください。空欄・使い回し・色コードやアイコンの漏れ・配点の偏り・「必ず」「当選」などの断定表現を自動で確認します。

## ファイル構成

```
index.html            画面（トップ / 読み込み / 今日の占い / 質問 / タイプ結果）
css/style.css         デザイン
js/data.js            質問・タイプ・占いの文章データ
js/fortune.js         タイプ判定と今日の占いのロジック（ブラウザと Node.js の両方で動く）
js/share-card.js      推し活タイプのシェア画像を作る
js/app.js             画面遷移・保存・共有
images/luna-cat.png   公式マスコット（三日月の上で眠る白猫）。トップ・読み込み・質問・案内カードなど
images/types/         推し活タイプごとの白猫（下の表。どのタイプの絵かは js/data.js の TYPES の image で指定）
images/apple-touch-icon.png  ホーム画面用アイコン
tests/check.js        データとロジックの検証
```

### 保存データ（localStorage）

| キー | 中身 |
| --- | --- |
| `oshi-luna-type` | 推し活タイプ診断の結果 |
| `oshi-luna-quiz` | 診断の途中の回答 |
| `oshi-luna-daily` | 今日の推し活占いの履歴（最大7日分） |

## 確認方法

```sh
node tests/check.js            # データとロジックの検証（Node.js）
python3 -m http.server 8000    # ブラウザで確認
```

GitHub Pages では `main` ブランチを更新すると数分で反映されます。
